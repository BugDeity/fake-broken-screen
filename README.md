# fake-broken-screen

一个 Windows 恶作剧小程序：运行后让屏幕看起来像坏掉了一样，有碎屏、漏液、彩色坏线、花屏、雪花等效果，按 **Esc** 随时恢复。

## 原理

启动时先截取当前桌面，再用一个一模一样的全屏窗口盖住，然后在截图上叠加各种故障效果。开头约 1.5 秒画面完全正常，之后屏幕瞬间"坏掉"。

## 使用

1. 运行 `build.bat` 编译出 `BrokenScreen.exe`。
2. 双击运行，在设置窗口里选好效果，点「开始」。
3. 运行时按 **Esc** 退出，会回到设置窗口。

也可以跳过界面直接发作（使用上次保存的设置）：

```bat
BrokenScreen.exe 30
```

表示 30 秒后发作。

## 设置项

- **损坏程度**：轻微 / 一般 / 严重 / 很严重 / 彻底报废，决定故障出现的频率和持续时间，全程固定不变。
- **效果**：画面撕裂、色差错位、电视彩条、雪花噪点、彩色条纹、反色闪烁、画面滚动、马赛克花屏、关机黑屏，以及坏线和程序绘制的裂纹，可任意组合。
- **素材**：`素材` 文件夹里的图片会叠加在屏幕上并一直显示，可单独设置：
  - 叠加方式：「正常」适合透明 PNG 或整张照片，「去黑底」适合黑底裂纹图，「去白底」适合白底污渍图
  - 位置：铺满全屏 / 拉伸全屏 / 原尺寸居中 / 原尺寸随机
  - 不透明度：5% ~ 100%
  - 按文件名顺序叠加，排在后面的盖在上面
- **时间**：延迟 N 秒后发作；持续 N 秒后自动恢复（0 表示一直坏下去）。

设置会保存在 exe 旁边的 `settings.ini` 里，下次打开自动读取。

## 自带素材

| 文件 | 内容 |
| --- | --- |
| `1-lcd-bleed-corner.png` | 右下角液晶漏液、紫蓝色边缘与彩色坏线 |
| `2-glass-crack-heavy.png` | 大面积放射状玻璃碎裂 |
| `3-glass-crack-corner.png` | 右上角局部玻璃裂纹，较轻 |

三张都是 1672 × 941 的透明 PNG。两张玻璃裂纹建议二选一。

## 编译

只需要 Windows 自带的 .NET Framework 4.x，不需要安装 Visual Studio：

```bat
build.bat
```

生成的 `BrokenScreen.exe` 不依赖其他文件；如果要用素材，把 `素材` 文件夹放在 exe 旁边即可。

## 注意

仅供娱乐。程序只是盖了一层全屏窗口，不会改动任何系统设置或文件。万一 Esc 没反应，可以按 Alt+F4 或 Ctrl+Alt+Del 结束。
